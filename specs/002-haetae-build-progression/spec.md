# Feature Specification: Phase 2 해태 성장·전문화

**Feature Branch**: `main`

**Created**: 2026-07-23

**Status**: Draft

**Input**: 사용자 설명 — 기존 페이즈 종료 3택 1 업그레이드 대신 해태 로봇별 세션 경험치와 레벨업을 도입한다. 각 해태는 레벨 1에서 일반형으로 시작하고, 레벨 2에 도달하면 근거리형·원거리형·균형형 중 하나를 개별 선택한다. 이미 반영된 사격 반동과 상향된 스폰 밀도·동시 생존 상한·소규모 웨이브는 현재 기준선으로 유지한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 해태별 독립 성장 (Priority: P1)

플레이어는 두 해태 로봇이 전투에 참여하는 정도에 따라 각자 경험치를 얻고 성장하는 모습을 확인한다. 해태 1호와 2호의 경험치와 레벨은 서로 섞이지 않으며, 플레이어는 어느 해태를 어느 경로에 배치하고 성장시킬지 판단한다.

**Why this priority**: 개별 경험치는 페이즈 종료 시 일괄 보상을 받던 기존 구조를 지속적인 전투 보상 구조로 바꾸는 기반이다. 독립 성장이 보장되지 않으면 로봇별 빌드 선택도 의미가 없다.

**Independent Test**: 두 해태 중 한 대만 좀비 전투에 참여시키고, 참여한 해태만 경험치를 얻는지 확인한다. 이후 두 해태가 같은 좀비에 모두 기여했을 때 각자의 경험치 기록에 보상이 적용되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 새 세션이 시작됨, **When** 두 해태의 성장 상태를 확인하면, **Then** 두 해태는 각각 레벨 1·경험치 0의 일반 해태로 시작한다.
2. **Given** 해태 1호만 피해를 준 좀비가 처치됨, **When** 처치 보상이 처리되면, **Then** 해태 1호만 해당 좀비의 경험치를 얻고 해태 2호의 경험치는 변하지 않는다.
3. **Given** 두 해태가 모두 피해를 준 좀비가 처치됨, **When** 처치 보상이 처리되면, **Then** 두 해태는 각자의 경험치 기록에 해당 좀비의 경험치를 얻는다.
4. **Given** 플레이어만 피해를 준 좀비가 처치됨, **When** 처치 보상이 처리되면, **Then** 어느 해태도 경험치를 얻지 않는다.
5. **Given** 해태가 레벨 2에 필요한 경험치를 초과해 획득함, **When** 보상이 처리되면, **Then** 해당 해태는 레벨 2가 되고 전문화 선택 가능 상태가 되며 초과 경험치 때문에 다른 해태의 성장 상태가 변하지 않는다.

---

### User Story 2 - 레벨 2 전문화 선택 (Priority: P1)

플레이어는 레벨 2에 도달한 해태마다 근거리형·원거리형·균형형 중 하나를 선택한다. 선택은 해태별로 이루어지므로 한 대는 근거리 방어를 맡기고 다른 한 대는 원거리 화력 지원을 맡기는 등 서로 다른 조합을 만들 수 있다.

**Why this priority**: 전문화 선택은 단순한 수치 상승이 아니라 로봇 배치와 지휘 방식을 바꾸는 Phase 2의 핵심 보상이다.

**Independent Test**: 두 해태를 레벨 2 선택 가능 상태로 만든 뒤 서로 다른 전문화를 선택하고, 각 해태가 선택한 역할만 적용받는지 확인한다. 같은 전문화를 두 해태에 선택할 수 있는지도 별도로 확인한다.

**Acceptance Scenarios**:

1. **Given** 해태 1호가 레벨 2에 도달함, **When** 플레이어가 성장 상태를 확인하면, **Then** 해태 1호에 대해서만 근거리형·원거리형·균형형 선택지가 제공되고 전투 진행은 선택을 기다리며 중단되지 않는다.
2. **Given** 해태 1호에 근거리형을 선택함, **When** 해태 2호의 상태를 확인하면, **Then** 해태 2호의 레벨·경험치·전문화는 변하지 않는다.
3. **Given** 두 해태가 모두 레벨 2에 도달함, **When** 플레이어가 해태 1호에 근거리형, 해태 2호에 원거리형을 선택하면, **Then** 두 전문화가 동시에 유지된다.
4. **Given** 두 해태가 모두 레벨 2에 도달함, **When** 플레이어가 두 해태 모두에게 같은 전문화를 선택하면, **Then** 중복 선택이 허용되고 두 해태 모두 해당 전문화를 적용받는다.
5. **Given** 전문화를 선택한 해태가 존재함, **When** 현재 세션이 계속되면, **Then** 선택은 변경되거나 초기화되지 않는다.
6. **Given** 새 세션이 시작됨, **When** 이전 세션에서 전문화했던 해태를 확인하면, **Then** 이전 선택은 유지되지 않고 레벨 1 일반 해태로 초기화된다.

### User Story 3 - 전투 역할이 달라지는 세 가지 빌드 (Priority: P1)

플레이어는 전문화 이름이나 능력치 표만 보는 것이 아니라 실제 전투 행동을 통해 각 빌드의 역할을 구분한다. 근거리형은 적 무리에 진입해 길목을 막고, 원거리형은 적과 거리를 유지하며 화력을 지원하고, 균형형은 접근 과정의 원거리 견제와 근접 교전을 함께 수행한다.

**Why this priority**: 전문화가 수치만 다르고 행동이 같으면 로봇 지휘와 경로 배치가 바뀌지 않아 빌드 시스템의 목적을 달성할 수 없다.

**Independent Test**: 동일한 경로·명령·적 구성에서 세 전문화를 각각 운용하고, 교전 거리·공격 방식·대상 접근 행동이 역할 정의와 일치하는지 비교한다.

**Acceptance Scenarios**:

1. **Given** 근거리형 해태가 적을 탐지함, **When** 교전을 시작하면, **Then** 적 무리에 접근해 근접 돌진·물기 계열 공격을 수행하고 복수의 밀집 적을 저지하는 데 특화된 행동을 보인다.
2. **Given** 원거리형 해태가 적을 탐지함, **When** 교전을 시작하면, **Then** 유효 사거리를 유지하며 원거리 공격을 수행하고 일반적인 교전에서 근접 돌진을 주 공격 방식으로 사용하지 않는다.
3. **Given** 균형형 해태가 적을 탐지함, **When** 교전을 시작하면, **Then** 접근 중 원거리 견제를 수행하고 적이 가까워지면 근접 공격으로 전환한다.
4. **Given** 서로 다른 전문화의 해태가 같은 명령을 받음, **When** 같은 경로를 방어하면, **Then** 두 해태는 명령의 목적과 배정 경로를 지키면서 각자의 교전 방식으로 전투한다.
5. **Given** 어느 전문화든 배터리가 고갈되거나 리퍼의 공격을 받음, **When** 기존 배터리·파괴 규칙이 발동하면, **Then** 전문화가 해당 위험을 무시하거나 기존 회복·복귀 흐름을 우회하지 않는다.

---

### User Story 4 - 성장 상태 확인과 비차단 선택 (Priority: P2)

플레이어는 전투 중 두 해태의 레벨, 경험치 진행도, 현재 전문화, 전문화 선택 대기 여부를 구분해 확인한다. 레벨업은 즉시 알려주되 강제로 전투를 멈추거나 페이즈 전환을 막지 않는다.

**Why this priority**: 개별 성장 상태가 명확하지 않으면 플레이어가 어느 해태를 성장시키고 무엇을 선택하는지 이해할 수 없다. 다만 성장 규칙과 전문화 전투가 먼저 성립해야 한다.

**Independent Test**: 두 해태의 경험치와 전문화 상태를 서로 다르게 만든 뒤 전투 화면과 선택 화면에서 각 상태가 올바른 로봇 식별자와 함께 표시되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 두 해태의 경험치가 서로 다름, **When** 성장 정보를 확인하면, **Then** 해태 식별자별 레벨과 현재/필요 경험치가 구분되어 표시된다.
2. **Given** 한 해태가 레벨 2에 도달함, **When** 레벨업이 처리되면, **Then** 해당 해태의 전문화 선택 가능 상태가 알려지지만 전투 시간은 멈추지 않는다.
3. **Given** 전문화 선택을 미룬 채 현재 페이즈를 클리어함, **When** 다음 페이즈가 시작되면, **Then** 선택 가능 상태는 유지되고 페이즈 전환은 정상 진행된다.
4. **Given** 두 해태가 동시에 전문화 선택 가능 상태가 됨, **When** 플레이어가 선택 화면을 열면, **Then** 대상 해태를 명확히 구분해 각각 선택할 수 있다.
5. **Given** 전문화를 선택함, **When** HUD와 로봇 상태를 확인하면, **Then** 선택한 전문화 이름과 역할을 해당 해태에 연결해 식별할 수 있다.

---

### User Story 5 - 페이즈 보상에서 지속 성장으로 전환 (Priority: P2)

플레이어는 페이즈를 클리어할 때 별도의 3택 1 업그레이드 화면에 흐름을 빼앗기지 않는다. 경로 개방·거점 회복·적 압박 증가는 기존처럼 이어지며, 해태의 성장은 전투 중 개별 경험치와 레벨업을 통해 진행된다.

**Why this priority**: 새 성장 루프가 기존 페이즈 종료 업그레이드와 중복되면 선택 체계가 복잡해지고 빌드 성장이 과도해질 수 있다.

**Independent Test**: Phase 1과 Phase 2를 각각 클리어하고 기존 3택 1 업그레이드가 나타나지 않는지, 경로 개방·거점 회복·다음 페이즈 시작은 유지되는지 확인한다.

**Acceptance Scenarios**:

1. **Given** Phase 1 또는 Phase 2의 모든 적을 처치하고 거점이 생존함, **When** 페이즈 클리어가 처리되면, **Then** 기존 3택 1 업그레이드 선택은 나타나지 않는다.
2. **Given** 페이즈가 클리어됨, **When** 다음 페이즈로 전환되면, **Then** 기존 거점 회복·새 경로 개방·다음 페이즈 시작 규칙은 유지된다.
3. **Given** 해태가 페이즈 중간에 레벨 2에 도달함, **When** 전문화 선택이 가능해지면, **Then** 플레이어는 페이즈 종료까지 기다리지 않고 해당 해태를 전문화할 수 있다.

### Edge Cases

- 두 해태가 같은 적에게 기여해 동시에 레벨 2에 도달하면 두 선택 가능 상태를 독립적으로 생성한다.
- 레벨 2 도달에 필요한 양보다 많은 경험치를 한 번에 얻어도 현재 범위의 최대 레벨인 2를 넘지 않는다.
- 해태가 피해를 준 뒤 파괴되고 해당 적이 나중에 처치되면, 처치 시점에 파괴 상태여도 그 해태의 기여 기록에 따라 경험치를 얻는다.
- 전문화 선택 전에 해태가 파괴되거나 Disabled 상태가 되어도 선택 가능 상태는 사라지지 않는다. 선택 결과는 로봇이 다시 전투 가능한 상태가 되었을 때 적용된다.
- 전문화 선택을 미룬 채 Phase 3을 클리어하면 세션 결과를 방해하지 않으며, 사용하지 않은 선택은 세션 종료와 함께 사라진다.
- 경험치 획득과 페이즈 클리어가 같은 순간 발생하면 경험치·레벨업을 먼저 확정한 뒤 페이즈 전환을 진행한다.
- 한 해태의 식별자나 성장 상태가 변경되어도 다른 해태의 경험치·레벨·전문화가 복사되거나 초기화되지 않는다.
- 같은 전문화를 두 해태에 선택할 수 있으며, 서로 다른 전문화를 선택하도록 강제하지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

#### 해태 경험치와 레벨

- **FR-001**: 시스템은 매 세션 시작 시 각 해태를 서로 독립된 레벨 1·경험치 0의 일반 해태로 초기화해야 한다(MUST).
- **FR-002**: 시스템은 해태별 현재 경험치, 현재 레벨, 다음 레벨 필요 경험치, 전문화 선택 가능 여부, 선택한 전문화를 별도로 추적해야 한다(MUST).
- **FR-003**: 좀비 유형마다 양수의 해태 경험치 보상을 정의해야 한다(MUST).
- **FR-004**: 해태가 처치 전 해당 좀비에게 피해를 주었다면 최종 처치 주체와 관계없이 해당 해태에 그 좀비의 경험치 보상을 지급해야 한다(MUST).
- **FR-005**: 두 해태가 같은 좀비에게 모두 피해를 주었다면 각 해태가 자신의 경험치 보상을 받아야 하며(MUST), 보상을 서로 나누거나 한 해태에만 귀속해서는 안 된다(MUST NOT).
- **FR-006**: 해당 좀비에게 피해를 주지 않은 해태는 그 좀비의 경험치를 얻지 않아야 한다(MUST NOT).
- **FR-007**: 해태 경험치는 현재 세션에서만 유지되고 새 세션 시작 시 초기화되어야 한다(MUST).
- **FR-008**: 이 기능 범위에서 해태의 최대 레벨은 2여야 한다(MUST).
- **FR-009**: 레벨 2 필요 경험치에 도달한 해태는 즉시 레벨 2 및 전문화 선택 가능 상태가 되어야 한다(MUST).
- **FR-010**: 레벨업과 경험치 획득은 페이즈 종료 여부와 독립적으로 전투 중 발생할 수 있어야 한다(MUST).

#### 해태 전문화

- **FR-011**: 레벨 1 해태는 기존 일반 해태의 근접 돌진·물기 공격, 명령, 배터리, 파괴·회복 규칙을 유지해야 한다(MUST).
- **FR-012**: 레벨 2에 도달한 각 해태에는 근거리형·원거리형·균형형의 세 전문화가 모두 제공되어야 한다(MUST).
- **FR-013**: 전문화는 해태별로 선택해야 하며(MUST), 두 해태가 같은 전문화 또는 서로 다른 전문화를 선택할 수 있어야 한다(MUST).
- **FR-014**: 전문화는 자동 선택되지 않아야 하며(MUST NOT), 플레이어가 선택하기 전까지 해당 해태는 레벨 2 일반형 행동을 유지해야 한다(MUST).
- **FR-015**: 한 번 선택한 전문화는 현재 세션 동안 변경하거나 취소할 수 없어야 한다(MUST NOT).
- **FR-016**: 전문화는 공격 방식, 선호 교전 거리, 접근 행동 중 최소 두 가지를 변경하여 전투 중 역할 차이를 식별할 수 있게 해야 한다(MUST).
- **FR-017**: 근거리형은 근접 돌진·물기 계열을 주 공격으로 유지하고, 밀집한 복수의 적 저지와 근접 생존에 특화되어야 한다(MUST).
- **FR-018**: 원거리형은 적과 유효 거리를 유지하며 원거리 공격을 주 공격으로 사용하고, 일반적인 교전에서 근접 돌진을 주 공격으로 사용하지 않아야 한다(MUST).
- **FR-019**: 균형형은 적에게 접근하는 동안 원거리 견제를 수행하고 근접 거리에서는 근접 공격으로 전환해야 한다(MUST).
- **FR-020**: 각 전문화는 다른 두 전문화보다 뚜렷한 강점과 약점을 각각 하나 이상 가져야 한다(MUST).
- **FR-021**: 전문화는 기존의 거점 사수·경로 순찰·기지 복귀 명령을 대체하거나 추가 명령을 요구해서는 안 된다(MUST NOT).
- **FR-022**: 모든 전문화는 기존 배터리 소모·충전·고갈, 리퍼 배터리 공격, HP 파괴·복원 규칙의 적용을 받아야 한다(MUST).

#### 성장 UI와 페이즈 흐름

- **FR-023**: HUD 또는 로봇 상태 화면은 해태별 식별자, 레벨, 현재/필요 경험치, 전문화 선택 가능 여부, 현재 전문화를 구분해 표시해야 한다(MUST).
- **FR-024**: 해태가 레벨 2에 도달하면 해당 해태를 식별할 수 있는 시각 알림을 제공해야 한다(MUST).
- **FR-025**: 레벨업 알림과 전문화 선택 가능 상태는 전투를 자동으로 일시정지하거나 페이즈 진행을 차단해서는 안 된다(MUST NOT).
- **FR-026**: 플레이어는 전문화 선택 가능 상태가 유지되는 동안 전투 중 원하는 시점에 대상 해태를 지정해 전문화를 선택할 수 있어야 한다(MUST).
- **FR-027**: Phase 1과 Phase 2 종료 시 기존 3택 1 업그레이드 선택을 제공하지 않아야 한다(MUST NOT).
- **FR-028**: 기존 페이즈의 거점 회복, 새 경로 개방, 적 구성, 승리·패배 규칙은 해태 성장 시스템 도입 후에도 유지되어야 한다(MUST).
- **FR-029**: 현재 반영된 사격 반동, 스폰 간격, 동시 생존 상한, 소규모 웨이브 구성은 이 기능 도입으로 이전 상태로 되돌아가거나 약화되어서는 안 된다(MUST NOT).

#### 검증 데이터

- **FR-030**: 개발 검증 기록은 해태 경험치 획득, 레벨 2 도달, 전문화 선택을 해태 식별자와 함께 구분해 기록해야 한다(MUST).
- **FR-031**: 경험치 획득 기록은 경험치 출처가 된 좀비 유형, 획득량, 획득 전후 경험치와 레벨을 확인할 수 있어야 한다(MUST).
- **FR-032**: 전문화 선택 기록은 선택한 해태, 선택 시점의 페이즈와 경과 시간, 선택한 전문화를 확인할 수 있어야 한다(MUST).
- **FR-033**: 반복 가능한 동일 조건의 전투 검증에서 같은 해태 기여와 처치 순서는 같은 경험치·레벨·전문화 가능 상태를 만들어야 한다(MUST).

### Scope Boundaries

#### In Scope

- 세션마다 초기화되는 해태별 경험치와 레벨 1→2 성장
- 레벨 2에서 해태별 근거리형·원거리형·균형형 전문화 선택
- 전문화에 따른 공격 방식·교전 거리·행동 차이
- 해태별 성장 HUD, 비차단 레벨업 알림과 선택 흐름
- 기존 페이즈 종료 3택 1 업그레이드 제거
- 기존 페이즈·난이도·반동 기준선 유지
- 성장과 전문화 밸런싱을 위한 개발 검증 기록

#### Out of Scope

- 돈, 상점, 시간 경과 수입과 구매 경제
- 플레이어 경험치·레벨·스킬 트리
- 플레이어용 신규 총기, 근접무기, 룬, 헤드샷 금전 보상
- 타임어택 또는 선택형 긴급 임무
- 해태 추가 구매, 출전 슬롯, 세 번째 전투 로봇
- 레벨 3 이상 성장, 전문화 이후 세부 특성 트리
- 세션을 넘는 영구 성장, 저장된 메타 진행
- 전문화 재선택·초기화·환불
- 현재 반영된 반동·스폰 밀도·동시 생존 상한·소규모 웨이브의 재설계

### Key Entities *(include if feature involves data)*

- **해태 성장 상태(Haetae Progression)**: 해태 식별자와 연결되는 세션 내 성장 정보. 현재 레벨, 현재 경험치, 다음 레벨 필요 경험치, 전문화 선택 가능 여부, 선택한 전문화를 가진다.
- **전투 기여(Combat Contribution)**: 특정 해태가 특정 좀비에게 피해를 주어 경험치 보상 자격을 얻었음을 나타내는 세션 내 관계. 좀비가 처치될 때 경험치 지급 여부를 결정한다.
- **경험치 보상(Experience Reward)**: 좀비 유형별로 해태에게 제공되는 성장 보상. 한 좀비에 여러 해태가 기여하면 각 적격 해태에 적용된다.
- **해태 전문화(Haetae Specialization)**: 근거리형·원거리형·균형형 중 하나. 공격 방식, 선호 교전 거리, 접근 행동, 강점과 약점을 정의한다.
- **전문화 선택 가능 상태(Specialization Ready)**: 레벨 2에 도달했지만 전문화를 아직 선택하지 않은 해태의 상태. 페이즈 전환과 로봇의 파괴·충전 상태를 넘어 현재 세션 동안 유지된다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100회의 독립 성장 검증에서 한 해태의 경험치 획득이 기여하지 않은 다른 해태의 경험치·레벨·전문화를 변경하는 사례가 0건이다.
- **SC-002**: 기준 난이도로 완료된 세션의 80% 이상에서 최소 한 해태가 Phase 2 시작 후 60초 이내에 레벨 2에 도달한다.
- **SC-003**: 기준 난이도로 완료된 세션의 80% 이상에서 두 해태 모두 Phase 3 시작 전 레벨 2에 도달해 전문화를 실제 전투에서 사용할 기회를 얻는다.
- **SC-004**: 처음 기능을 접한 플레이테스터의 90% 이상이 별도 설명 없이 15초 이내에 레벨 2가 된 해태를 식별하고 전문화를 선택한다.
- **SC-005**: 플레이테스터의 80% 이상이 전투 장면만 보고 근거리형·원거리형·균형형의 주 역할을 올바르게 구분한다.
- **SC-006**: 플레이테스터의 70% 이상이 해태 전문화 선택 때문에 로봇의 경로 배치 또는 역할 분담을 한 번 이상 다르게 결정했다고 응답한다.
- **SC-007**: 최소 30회의 전문화 선택을 포함한 플레이테스트에서 세 전문화가 각각 전체 선택의 20% 이상을 차지한다.
- **SC-008**: 해태 성장 시스템이 적용된 기준 세션의 전체 완료 시간은 기존 목표인 10~15분 범위를 유지한다.
- **SC-009**: Phase 1·Phase 2 클리어 검증의 100%에서 기존 3택 1 업그레이드 없이 거점 회복·경로 개방·다음 페이즈 시작이 정상 완료된다.
- **SC-010**: 동일한 전투 조건을 반복한 검증에서 해태별 경험치, 레벨 2 도달 시점, 전문화 선택 가능 상태가 100% 동일하게 재현된다.

## Assumptions

- 이 문서의 “Phase 2”는 기존 MVP 이후의 제품 고도화 단계이며, 게임 내부의 `Phase 2` 전투 구간과는 구분한다.
- 현재 세션은 기존과 동일하게 3개 페이즈와 10~15분 목표를 유지한다.
- 해태 경험치와 전문화는 한 세션 안에서만 유효한 런타임 빌드이며 영구 성장 요소가 아니다.
- 이번 범위에서는 레벨 2가 최대 레벨이다. 레벨 2에 도달한 뒤 추가 경험치는 획득하지 않는다.
- 좀비 유형별 경험치와 레벨 2 필요 경험치의 구체 값은 SC-002·SC-003을 만족하도록 후속 계획과 밸런싱에서 확정한다.
- 경험치 자격은 해당 좀비가 살아 있는 동안 해태가 한 번 이상 피해를 주었는지로 판정하며, 피해량 비율이나 최종 타격 여부는 사용하지 않는다.
- 한 좀비에 여러 해태가 기여하면 보상을 분할하지 않고 적격 해태마다 전체 경험치를 지급한다.
- 전문화를 아직 선택하지 않은 레벨 2 해태는 레벨 1의 일반형 전투 행동을 유지한다.
- 전문화는 기존 세 가지 로봇 명령, 개별 선택, 배터리 관리와 함께 동작한다.
- 현재 구현된 사격 반동·총구 섬광·명중 피드백과 상향된 스폰 밀도·동시 생존 상한·소규모 웨이브를 Phase 2의 기준선으로 간주한다.
- 돈·상점·플레이어 무기·근접무기·타임어택은 2번 플레이테스트 피드백에서 파생된 후속 후보이지만, 해태 성장 루프의 효과를 먼저 검증하기 위해 이번 명세에서는 제외한다.
