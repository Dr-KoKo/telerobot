# 텔레로봇 MVP 짧은 플레이테스트 설문

빌드 버전: `{{BUILD_VERSION}}`  
배포 파일: `{{ARCHIVE_NAME}}`  
예상 응답 시간: 약 3분

Microsoft Forms나 Google Forms에 아래 문항을 순서대로 옮겨 사용합니다. 이름과 이메일은 수집하지 않습니다.

## 설문 제목

`텔레로봇 MVP v{{BUILD_VERSION}} 플레이테스트`

## 설문 설명

텔레로봇 MVP를 플레이해 주셔서 감사합니다. 설치 경험, 조작, 재미와 난이도를 확인하기 위한 약 3분짜리 설문입니다. 이름이나 연락처는 받지 않습니다. 게임을 실행하지 못했다면 1~2번과 10번만 답해도 됩니다.

## 문항

1. `* 어떤 경로로 게임을 설치했나요?`  
   객관식: Microsoft Store / itch.io ZIP

2. `* 게임이 정상적으로 실행됐나요?`  
   객관식: 정상 실행 / Windows 경고 후 실행 / 실행되지 않음 / 플레이 도중 종료됨

3. `가장 멀리 진행한 단계는 어디인가요?`  
   객관식: 시작 화면 / Phase 1 / Phase 2 / Phase 3 / 승리

4. `이동·조준·사격 조작은 편했나요?`  
   1~5 선형 척도: 1 매우 불편함 / 5 매우 편함

5. `로봇 선택과 명령 사용법은 이해하기 쉬웠나요?`  
   1~5 선형 척도: 1 매우 어려움 / 5 매우 쉬움

6. `전투는 재미있었나요?`  
   1~5 선형 척도: 1 전혀 재미없음 / 5 매우 재미있음

7. `전체 난이도는 어땠나요?`  
   객관식: 매우 쉬움 / 쉬움 / 적당함 / 어려움 / 매우 어려움

8. `가장 좋았던 점은 무엇인가요?`  
   장문형, 선택

9. `가장 먼저 개선했으면 하는 점은 무엇인가요?`  
   장문형, 필수

10. `실행 문제나 버그가 있었다면 알려주세요.`  
    장문형, 선택. 안내 문구: `발생 직전에 한 행동, 다시 발생하는지, Windows 버전을 적어주세요. 문제가 없으면 비워두세요.`

## 권장 Forms 설정

- 응답 대상: 링크가 있는 누구나 응답 가능
- 이름 기록: 끔
- 한 사람당 한 번만 응답: 끔 — 로그인을 요구하지 않기 위함
- 질문 순서 섞기: 끔
- 1~2번과 9번만 필수, 나머지는 선택
- 완료 메시지: `테스트와 의견 감사합니다. 다음 버전 개선에 반영하겠습니다.`

## 운영 메모

- 실행하지 못한 응답은 1, 2, 10번을 중심으로 확인합니다.
- 같은 문제가 두 번 이상 보고되면 먼저 재현합니다.
- 새 빌드마다 `{{BUILD_VERSION}}`을 갱신해 버전별 응답을 구분합니다.
- 스크린샷이나 `Player.log`가 필요하면 응답자에게 별도로 요청합니다. 로그에는 사용자 폴더 경로가 포함될 수 있으므로 본인이 내용을 확인하고 동의할 때만 받습니다.
